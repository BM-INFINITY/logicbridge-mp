# Frontend Builder Components

This directory contains visual canvas builder subcomponents for the React Flow workflow editor.

## Subcomponents
- **`toolbar/Toolbar.jsx`**: Top header toolbar containing Back button, workflow rename input, Templates, AI modal toggle, Save, and Run controls.
- **`canvas/Canvas.jsx`**: React Flow graph canvas renderer, custom node definitions, background grid, controls, and minimap.
- **`palette/NodePalette.jsx`**: Drag source sidebar palette categorized into Triggers, Actions, and Logic.
- **`panels/AIPanel.jsx`**: AI prompt modal drawer for automated workflow generation.
